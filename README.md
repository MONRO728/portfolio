## 🚀 Texnologiyalar

- **React 19** + **Vite 6**
- **Tailwind CSS v4** (Utility-first zamonaviy dizayn tizimi)
- **Lucide React** (Zamonaviy vektor ikonkalari)

## 🌐 Deploy Qilish Yo'riqnomasi

Loyihaning barcha fayllari `dist/` papkasiga nisbiy yo'llar bilan (`base: './'`) to'g'ri moslangan holda yig'iladi.

### Variant 1: Vercel orqali deploy qilish (Tavsiya etiladi - 1 daqiqa)
1. [vercel.com](https://vercel.com) saytiga kiring va GitHub orqali ro'yxatdan o'ting.
2. **"Add New Project"** tugmasini bosing va ushbu repozitoriyni tanlang.
3. Framework avtomatik ravishda **Vite** deb aniqlanadi.
4. **"Deploy"** tugmasini bosing. Sayt bir necha soniyada ishga tushadi!

### Variant 2: GitHub Pages orqali deploy qilish
1. Repozitoriyni GitHub profilingizga push qiling.
2. Loyihani build qiling:
   ```bash
   npm run build
   ```
3. GitHub repozitoriyangiz **Settings -> Pages** bo'limiga kiring.
4. Source bo'limida **GitHub Actions** yoki `gh-pages` / `dist` branchini tanlang.
